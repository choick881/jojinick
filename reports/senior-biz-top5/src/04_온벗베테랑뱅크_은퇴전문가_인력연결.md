# 한 장 요약 {.nobreak}

<span class="chap">EXECUTIVE SUMMARY</span>

<div class="box sum" markdown="1"><span class="bt">온벗 베테랑뱅크는 무엇인가</span>

**은퇴한 베테랑(55~72세)의 경력을 영상 프로필로 기록하고, 먼저 온벗 안에서 클럽 리더·안부 활동가·강사로 함께 일한 뒤, 검증된 분들을 복지관·학습관·기업·가정의 일거리로 연결하는 인재 은행**입니다. 이력서보다 "함께 일해 본 신뢰"가 상품입니다.

</div>

|---|---|
| 해결하는 문제 | 퇴직 52.9세 ↔ 국민연금 65세, **10년 이상 소득 공백** / 은퇴자 69.4%가 73세까지 일하고 싶어 함 / 기관은 믿을 만한 강사·인력을 찾기 어려움 |
| 핵심 가치 | 은퇴자: 경력을 살린 일·소득·자존감 / 기관: 검증된 베테랑 / 온벗: 사업 확장의 인력 엔진 |
| 1월 범위 | 인재 모집·등록 (1기 20명 목표), **내부 위촉 6명** (클럽 리더 4·안부 활동가 2) |
| 외부 사업 시점 | 2분기: 교육 용역(강사 연결), 어르신 집 안전 손보기 / 하반기: 법인 전환 후 유료직업소개 등록 검토 |
| 1월에 하지 않는 것 | 근로자파견 (자본금 1억 원·사무실 20㎡·고용노동부 허가 필요), 등록 없는 유료 직업소개 |

| 런칭 예산 | 약 150만 원 |

## 1-1. 기업 개요 (첨부 자료 기준)

| 항목 | 내용 |
|---|---|
| 설립 | 2000년, 도쿄가스 퇴직자 **우에다 겐지**가 은퇴 동료 15명과 함께 |
| 규모 | 2026년 4월 기준 등록 사원 **1,233명**, 평균 나이 **71.4세**, 지난 회계연도 매출 **8억 5천만 엔** |
| 업무 | 가스 계량기 검침, 가스 기기 점검 등 **경험과 꼼꼼함이 핵심인 현장 업무** |
| 채용 | 이력서 심사 대신 **30년 함께 일한 동료 명부**로 검증 |
| 철학 | **"사원이 고객보다 먼저, 고객이 주주보다 먼저"** |

## 1-2. 성공 원리

1. **업무 선별** — 무거운 짐·야간 근무 대신, 육체적 힘보다 **경험·신뢰·눈썰미**가 중요한 일을 골랐습니다. 안전사고 위험을 낮추고 고객 신뢰는 높였습니다.
2. **검증 비용 제로** — 같은 회사에서 수십 년 일한 동료가 서로를 보증합니다. 기업은 이력서 검증 비용을 아끼고 품질을 확신합니다.
3. **이중 해결** — 기업의 구인난과 은퇴자의 구직난을 동시에 풀었습니다.
4. **사원 우선 철학** — 고령 근로자가 존중받는 문화가 이직률을 낮추고 서비스 품질을 높였습니다.

## 4-3. "온벗 베테랑" 인증 제도 (한국판 동료 명부)

1. **등록**: 온라인 신청서 + 경력 증빙 + 추천인 1명 (전 직장 동료 우대)
2. **영상 인터뷰 (1시간)**: 조피디가 촬영 → AI로 **경력 프로필 1장 + 1분 소개 영상** 제작
3. **기본 교육 (8시간)**: 시니어 이해·안전·개인정보·온벗 서비스 기준
4. **현장 검증 (3개월)**: 온벗 내부 활동으로 평가 (출석, 회원 만족도, 동료 평가)
5. **베테랑 인증**: 외부 연결 대상. 매년 갱신

## 5-2. 매칭·품질 관리

- **배정 원칙**: 거주지 30분 이내, 경력·성향 매칭, 신규는 선배와 2인 1조
- **평가**: 매 활동 후 고객 만족도(5점) + 분기 동료 평가 + 연 1회 대표 면담
- **보상 원칙 (고레이샤 철학)**: 베테랑 몫 70% 원칙, 연말 성과 공유, 존칭·존중 문화
- **건강 관리**: 연 1회 건강 상태 자기 신고, 무리한 일정 배정 금지

## 5-3. 계약 구조 주의 (불법 파견·위장 도급 방지)

<div class="box warn" markdown="1"><span class="bt">반드시 지킬 선</span>

- 온벗이 기관에 **사람을 보내 기관의 지휘를 받게 하는 구조는 "근로자파견"**이 될 수 있습니다 → 허가 없이 하지 않습니다.
- 용역 계약에서는 **업무 내용·결과물·진행 방식을 온벗이 책임**지고, 기관은 결과를 받는 구조로 설계합니다.
- 기관이 베테랑을 직접 채용하도록 소개하고 수수료를 받는 것은 **직업소개**이며 등록이 필요합니다.
- 내부 위촉자가 정해진 시간·장소에서 지휘를 받으며 일하면 근로자로 판단될 수 있어 **단시간 근로계약**이 맞을 수 있습니다.
- → 런칭 전 노무사 자문 1회로 계약서 3종(위촉·근로·용역)을 확정합니다.
