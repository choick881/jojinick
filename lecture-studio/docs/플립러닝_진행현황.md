## 3. 시험으로 알게 된 것
- **다시 말하기를 쉼 없이 바로 이어 하면 받아쓰기(Whisper)가 반복을 한 번만 적어** 글 기반 감지로는 못 찾음.
  NG 낱말("다시 할게요" 등)이나 쉼이 끼면 찾음. 소리 기반 반복 감지는 다음 과제.
- 샘플 영상은 표지 슬라이드 1장 + 교수 카메라 원형 창 + 녹화 위젯. 카메라 창의 화면 잡음은 0.1% 수준 → 기준 1%로 충분.
- 받아쓰기 속도(4코어 CPU): medium 은 영상 길이의 1.9배, small 은 0.5배지만 오인식이 많음 → 기본은 medium, GPU 없는 저사양 PC 는 small + 꼼꼼한 검수.
- 번역(en)이 빈 작업에서 ⑥이 멈추던 기존 문제 수정 (내용 있는 언어만 자막 생성).
- 3분50초 샘플 대본 끝의 녹화 중 잡담("왜 PPT를 안 넘겨?… 미치겠다")은 'NG·혼잣말 의심'으로 잡힘 (단위 시험에 포함).
