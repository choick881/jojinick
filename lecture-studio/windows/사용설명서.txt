HY FLIP 강의 편집기 — 사용 설명서 (Windows)
=====================================================

■ 처음 한 번: 설치
  1) 이 폴더(lecture-studio)를 원하는 곳에 둡니다. 예: C:\강의편집기
     (경로에 한글이 있어도 되지만, 너무 깊은 폴더는 피하세요)
  2) windows 폴더의 「1_설치하기.bat」 을 더블클릭합니다.
     - 「Windows의 PC 보호」 파란 창이 뜨면 「추가 정보」 → 「실행」을 누릅니다 (인터넷에서 받은 파일이라 뜨는 안내).
     - Python 3.12, ffmpeg, 받아쓰기 모델(약 1GB)을 이 폴더 안에 설치합니다 (20~40분).
     - 끝나면 바탕화면에 「강의 편집기」 바로가기가 생깁니다.

■ 강의 영상 편집 (매번)
  1) 바탕화면 「강의 편집기」 위에 강의 영상(mp4 등)을 끌어다 놓습니다.
     - 영상은 복사하지 않고 원래 자리에서 읽습니다. 용량 제한이 없습니다 (60분 이상도 가능).
  2) 강의 제목, 교수님 성함, 동의 여부를 입력합니다.
     - AI(Claude) 사용은 학교 보안 정책에서 허용된 경우에만 '예'를 고르세요.
       '아니오'면 자막은 받아쓴 글 그대로, 요약·퀴즈는 만들지 않습니다. 영상·음성은 어느 경우에도 밖으로 나가지 않습니다.
  3) 자동 처리 (영상 길이의 약 1~2배 시간):
     영상 정리(1080p·음량·녹화 위젯 가림·립싱크 보정) → 받아쓰기 → 슬라이드 전환 → 자막 → 챕터 → 군더더기 컷 제안 → 산출물
  4) 끝나면 결과 폴더와 「검수 화면」(인터넷 창)이 열립니다.
     - 자막·챕터·군더더기 컷을 확인하고 고친 뒤 「승인」을 누릅니다.
     - 군더더기 컷은 체크한 것만 잘립니다 (자동으로 자르지 않습니다).
  5) 검수 창에서 Enter → 「다시 만들기」를 고르면 승인 내용이 반영된 최종본이 만들어집니다.

■ 결과물 (작업 폴더의 out 폴더)
  영상_한글자막.mp4 / 영상_자막없음.mp4 / 영상_자막선택형.mp4
  자막\*.srt, *.vtt (LMS 업로드용), 자막\챕터.vtt
  챕터_타임스탬프.txt (LMS·유튜브 설명란에 붙여 넣기)
  문서\강의스크립트·자막스크립트 (docx·html·txt), 인쇄용PDF
  검수상태.txt (승인 전에는 '검토 대기'), 실행로그.txt

■ 예전 작업 다시 열기
  「강의 편집기」를 그냥 더블클릭 → 최근 작업 번호를 고릅니다.

■ 처리 시간 (참고)
  일반 사무용 PC(4코어, 그래픽카드 없음): 10분 강의 약 20분, 60분 강의 약 2시간.
  처리하는 동안 창을 닫지 마세요. 밤에 걸어 두고 다음 날 검수해도 됩니다.

■ 문제가 생기면
  - 「먼저 1_설치하기.bat 을 실행하세요」 → 설치를 먼저 합니다.
  - 립싱크 자동 보정이 안 되면 작업 폴더의 job.yaml 에서 av_offset_ms 에 숫자를 넣습니다
    (예: 입이 소리보다 늦으면 -250).
  - 실행로그.txt 를 담당자에게 보내 주세요 (영상은 보내지 않아도 됩니다).
