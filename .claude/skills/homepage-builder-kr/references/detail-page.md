# 상품 상세페이지 가이드 (Phase 5.5)

한국 소비자는 쇼핑몰·스마트스토어에서 **세로로 긴 상세페이지**에 익숙하다. 웹사이트 상세페이지도 같은 흐름을 따르되, 텍스트는 이미지에 굽지 않고 **HTML로 작성**한다(검색·접근성·수정 용이).

---

## 1. 레이아웃 기본

- 본문 폭: 모바일 100%, 데스크톱 상세 영역 **최대 860px** 가운데 정렬 (오른쪽에 구매 박스를 sticky로 둘 수 있으면 1200px 그리드 2열)
- 섹션 사이 여백 크게(모바일 72~96px), 섹션마다 **한 가지 메시지**
- 모바일 하단 고정 구매 바: 가격 + 수량 + "예약/구매하기"
- 이미지 비율: 세로 컷 2:3, 디테일 컷 1:1, 와이드 컷 3:2

## 2. 섹션 순서 (기본형)

| # | 섹션 | 목적 | 내용 예시 |
|---|---|---|---|
| 1 | 상단 구매 영역 | 바로 사기 | 대표 이미지, 상품명, 가격, 용량·인분, 옵션, 수량, CTA |
| 2 | 후킹 | 3초 안에 붙잡기 | 고객의 상황 한 문장 + 해결 한 문장 |
| 3 | 공감 | "내 얘기다" | 고객이 겪는 불편 3가지 |
| 4 | 구성 | 무엇이 들어있나 | 구성품 사진 + 이름 + 양 |
| 5 | 차별점 | 왜 여기서 | 제조 방식·재료·시간·사람, 숫자로 3가지 |
| 6 | 사용/섭취 방법 | 불안 제거 | 보관·데우기·맛있게 먹는 법 단계별 |
| 7 | 신뢰 | 믿을 근거 | 위생·인증·자격·후기·제조 라벨 예시 |
| 8 | 정보 고시 | 법정 표시 | 아래 3. 표 |
| 9 | 픽업/배송·교환/환불 | 구매 후 걱정 제거 | 시간·장소·조건 |
| 10 | FAQ | 마지막 의문 해소 | 질문 5개 내외 |
| 11 | 마무리 CTA | 행동 | 가격 재확인 + 버튼 |

## 3. 표시 의무 항목 (식품 예시)

식품을 판매하면 상세페이지에 아래 정보 자리를 반드시 둔다. 정확한 의무 범위는 영업 유형(예: 즉석판매제조·가공업)과 판매 방식(매장/통신판매)에 따라 다르므로 **관할 기관 확인 전에는 "사업자 확인 필요" 표시**를 남긴다.

- 제품명 · 식품유형
- 내용량(중량/인분)
- 원재료명 및 원산지
- 알레르기 유발 물질
- 제조일시 · 소비기한 (당일 제조라면 라벨 예시 이미지)
- 보관 방법 (냉장 0~10℃ 등)
- 제조원/판매원 (상호·주소)
- 통신판매 시: 사업자 정보, 교환·환불 조건

## 4. 카피 규칙

- 효능·치료·"무첨가 100%" 같은 단정·과장 표현 금지. 사실(재료, 시간, 방법)로 말한다.
- 숫자는 구체적으로: "아침 7시에 만든", "1인분 180g", "12종 중 매일 8종".
- 문장은 짧게, 한 문단 2~3줄. 헤드라인은 15자 내외, `keep-all` + 의미 단위 줄바꿈.

## 5. 시안 3종 만드는 법

같은 정보 구조로 **톤만 다른 3안**을 만든다.

| 안 | 톤 | 특징 |
|---|---|---|
| A | 따뜻한 집밥 | 크림 배경, 손글씨 포인트, 자연광 사진, 이야기형 카피 |
| B | 깔끔한 델리 | 흰 배경, 큰 숫자·아이콘 정보형, 탑뷰 정물 사진 |
| C | 프리미엄 한식 | 짙은 배경, 명조 제목, 측면광 사진, 여백 많은 구성 |

각 시안은 375px·860px 스크린샷으로 비교해 보여주고, 사용자가 고른 안의 컴포넌트를 실제 사이트 `/products/[slug]` 템플릿으로 옮긴다.
