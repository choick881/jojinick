## 2 As-Is · To-Be

**As-Is · 현재 문제점 \***
```
① 사업 홍보: 공문·이메일·개별 안내 중심이라 교수님께 사업 내용·제작 절차를 매번 반복 설명하며, 한곳에서 확인할 창구가 없음.
② 제작 신청: 한글·메일 신청서 수신 → 엑셀 수기 입력 → 접수 확인·준비물 안내 메일 개별 작성. 담당자 1인 기준 신청 1건당 약 60분 소요.
③ 셀프 스튜디오 예약(12곳): 공유 구글 캘린더에 교수가 직접 입력하는 방식으로 승인 단계가 없음. 예약 취소·변경률 약 20%, '촬영 3일 전부터 변경 불가' 규칙을 담당자가 수기로 확인.
④ 안내 오류: 안내 메일 누락·오기재, 이중 예약이 학기당 약 5건 발생.
⑤ 홍보 시각물: 로고·페이지 시안·사진 1세트를 외주·수작업으로 만드는 데 약 30일 소요.
⑥ 현황 보고: 신청·제작 현황을 보고 때마다 수작업으로 집계.
```

**To-Be · AI 적용 개선 방안 \***
```
① 홍보: Claude로 기획·카피·코딩한 HY FLIP 홍보 홈페이지에서 사업소개·제작 절차·스튜디오·사례·FAQ를 한 주소로 상시 안내(데스크톱·모바일).
② 제작 신청: 웹 신청 폼 → 구글 시트 자동 기록·중복/누락 자동 검사(Apps Script) → 접수 확인·준비물 메일 자동 발송, 담당 PD 알림. 수기 입력 0건.
③ 스튜디오 예약: 홈페이지 예약 화면에서 빈 시간 선택 → AI 사전 검토(승인 과목·3일 규칙·중복·강의안 첨부 여부) → 규칙 충족 시 즉시 자동 승인, 예외만 담당자 확인(AI가 사유·대안 시간·안내문 초안 제시) → 구글 캘린더 자동 등록, 확정·D-3·D-1 안내 자동 발송.
④ 홍보 시각물: 문답형 메타 프롬프트 + GPT 이미지 생성 파이프라인으로 2일 이내 내부 제작.
⑤ 후반작업: 촬영 영상의 AI 자막·요약·퀴즈 생성 → 홈페이지 '제작 사례'에 게시.
⑥ 현황: 시트 데이터 기반 대시보드 자동 갱신으로 보고 자료 즉시 생성.
```
