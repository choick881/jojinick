## 공통 패턴 정리
1. **첫 화면에 "누가 · 무료/지원 · 신청 방법"** → 교수님의 첫 질문에 바로 답
2. **장비·공간은 사진으로** → 텍스트보다 실사가 신뢰를 줌 (→ GPT 실사 이미지 필요)
3. **절차는 번호 단계로** → 01·02·03·04
4. **전통 + 현대 로고 체계** → 인장(공식 문서용) + 모노그램(웹·영상용)
